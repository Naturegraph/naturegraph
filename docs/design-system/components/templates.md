# Templates

> Squelettes de page sans contenu réel. Définissent la grille et les régions.

| Template          | Statut | Régions                               | Usage                 |
| ----------------- | ------ | ------------------------------------- | --------------------- |
| Section           | ❌     | container max-w + padding responsive  | Landing (9x)          |
| ImageTextLayout   | ❌     | image / texte 50/50 (reversible)      | Landing (4x)          |
| AuthFormLayout    | ❌     | center + card + footer link           | Signup, Login         |
| OnboardingLayout  | ❌     | header + content + footer (back/next) | Onboarding (4 étapes) |
| LandingPageLayout | 🟡     | header + sections + footer            | Landing               |
| AppLayout         | 🟡     | header + main + footer                | App connectée         |

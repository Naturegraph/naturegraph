## Filtre "Demandes d'aide" (Rencontres sans espece determinee)

Retire en 2026-07-23, re-active a la demande de Nicolas. Une case dans le panneau
Filtres (au-dessus de "Par type de partages") qui ne garde QUE les Rencontres
nature dont l'espece n'est pas determinee : exactement les posts qui affichent le
badge "Espece non determinee" (case "Je ne connais pas l'espece" a la
publication).

- Socle deja en place (FeedFilters.helpOnly propage jusqu'a postService, comptage
  dans le badge filtres, cle i18n) : seule la case UI avait ete supprimee.
- Definition backend corrigee : on filtre sur l'ABSENCE DE NOM d'espece, cale sur
  le badge du fil, et non sur identification_status='pending' :
  `type = 'nature_encounter' AND species_name IS NULL AND scientific_name IS NULL`.
  Pourquoi : certains 'pending' portent un nom (ils affichent donc une espece), et
  les Instant nature (paysages) n'ont jamais d'espece -> exclus. Verifie en prod :
  12 vraies demandes d'aide (vs 37 avec l'ancien proxy 'pending').
- UI : icone HelpCircle dans un carre plein violet (meme format que Rencontre /
  Instant), titre "Rencontres dont l'espece reste a identifier" (equilibre sur
  deux lignes en mobile via text-balance), sans sous-titre.
- Cocher "Demandes d'aide" DECOCHE automatiquement Instant nature (et reciproque) :
  le filtre ne vise que les Rencontres.

Rend obsolete le ticket NG-072 (purge du code mort helpOnly) : on le reactive.

## Echanges : barre d'actions sur une seule ligne

"Proposer une espece" tombait sur une 2e ligne. On resserre les 3 actions :

- gap-x-3 -> gap-x-1, padding des boutons px-2 -> px-1.5,
- suppression des puces de separation (les points), grosses consommatrices de
  largeur,
- bouton "Reagir" : plus de libelle, on affiche TOUJOURS le compteur (coeur +
  "0" au repos). Cliquer fait passer le coeur en emoji et le "0" a "1". Le libelle
  reste porte par aria-label.

Egalement livre (menu ellipsis) : ancre en haut a droite, hors du flux ; c'est la
date qui passe a la ligne, plus le menu (fin du decalage vide).

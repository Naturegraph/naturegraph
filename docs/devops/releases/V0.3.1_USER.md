# Naturegraph V0.3.1 : ce qui change pour toi

> Mise a jour du 21 juillet 2026. Pas besoin de te reconnecter.

## 🔔 Notifications : quelques ajustements

- **Sur telephone**, le panneau des notifications garde maintenant la meme
  taille quel que soit l'onglet choisi.
- Les **annonces de l'equipe** s'affichent en entier, sans etre coupees.
- Les notifications de **plus de 30 jours** sont effacees automatiquement :
  ton centre de notifications reste concentre sur ce qui est recent.

Bonnes observations 🌿

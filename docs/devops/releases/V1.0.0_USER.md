## Texte plus long (Discord, mail, blog)

**Titre** : `On passe officiellement en V1.0.0 🌿`

**Corps** :

```
Salut a toi 👋

Cette semaine on a beaucoup travaille avec vos retours
pour rendre Naturegraph plus stable et plus fluide.

Ce qui change pour toi :

• Une nouvelle section Blocages dans tes Parametres :
  tu peux maintenant gerer toi-meme les publications
  que tu as masquees et les comptes que tu as bloques,
  et faire marche arriere si tu changes d avis.

• Le bouton Migrer fonctionne enfin pour de vrai :
  tu suis un autre naturaliste, tu vois ses observations,
  ton profil apparait dans ses migrateurs.

• Tes photos de profil et bannieres s actualisent
  partout dans l app instantanement (avant ca prenait
  un refresh).

• Si tu reviens apres une longue pause et que la session
  est cassee, l app te redirige proprement vers la page
  de connexion (avant tu avais des messages d erreur peu
  clairs).

Toutes ces ameliorations sont deja en ligne, tu n as
rien a faire de special.

Merci enormement pour votre engagement dans cette beta,
chaque retour qu on recoit nous aide a rendre le produit
meilleur 🦔

A tres vite dans tes prochaines migrations.
L equipe Naturegraph
```

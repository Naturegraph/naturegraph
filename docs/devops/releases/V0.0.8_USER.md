# Naturegraph V0.0.8 : Ce qui change pour toi

> Mise a jour du 1er juillet 2026. Pas besoin de te reconnecter.

Une petite mise a jour pour fluidifier l'arrivee des nouveaux membres.

## ✉️ Invitations plus robustes

- Si un lien d'invitation a deja ete ouvert ou a expire (ca arrive quand la
  messagerie verifie les liens automatiquement), la personne arrive maintenant
  directement sur la page d'inscription, avec un message clair, au lieu de rester
  bloquee. L'acces etant ouvert, elle cree simplement son compte.

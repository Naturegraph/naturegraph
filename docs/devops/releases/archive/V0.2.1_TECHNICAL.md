## 2. Probleme corrige

Le panneau de la cloche et la page plein ecran affichaient des choses
differentes pour la meme notification.

Cause racine : `components/notifications/NotifItem.tsx` existait pour partager
les sous-composants, et son en-tete l'annonce explicitement, mais
`NotificationsPanel.tsx` avait garde ses propres copies locales de `NotifIcon`,
`NotifChip`, `Avatar`, `getMessage` et `resolveDeepLink`. Les corrections de
NG-046 ont ete appliquees a une seule des deux copies, d'ou des defauts qui
semblaient corriges mais restaient visibles sur l'autre surface.

Trois ecarts constates, tous cote page plein ecran :

| Ecart                   | Avant                                                | Apres                                    |
| ----------------------- | ---------------------------------------------------- | ---------------------------------------- |
| Libelle de reaction     | `love`, cle anglaise brute du trigger SQL            | `❤️ J'adore !`                           |
| Publications regroupees | singulier + texte d'UNE seule publication en dessous | `a publie 3 nouvelles rencontres nature` |
| Avatar sans photo       | initiales (`LE`, `PA`)                               | hermine officielle                       |

L'avatar est le plus revelateur : la regle "hermine partout" date du
2026-05-19 et n'avait jamais atteint la page, faute de composant partage.

---

## 3. Correction

- `NotifItem.tsx` devient la source unique. Les copies locales du panneau sont
  supprimees, les deux surfaces importent les memes fonctions.
- `getMessage` accepte desormais `groupCount`.
- `Avatar` partage adopte l'hermine (comportement decide, jusqu'ici applique
  seulement dans le panneau).
- Cle `home.notifications.messagePostGrouped` ajoutee dans `fr.json` ET
  `en.json`. Elle n'existait dans aucun des deux : le texte ne vivait que dans
  un `defaultValue` francais, donc l'interface anglaise affichait du francais.
  Le `defaultValue` est retire pour qu'une cle manquante redevienne visible.
  Meme classe de probleme que NG-051.
- 8 tests unitaires verrouillent les deux regles (libelle de reaction et
  regroupement). C'est l'absence de test qui avait laisse la divergence passer.

## 4. Differences volontairement CONSERVEES entre les deux surfaces

A ne pas confondre avec des bugs, et a ne pas "corriger" par reflexe :

| Element                  | Panneau cloche | Page plein ecran                                                |
| ------------------------ | -------------- | --------------------------------------------------------------- |
| Troncature du texte      | 2 lignes       | aucune (Nicolas 2026-05-25, les notifs system doivent respirer) |
| Suppression par balayage | oui            | non                                                             |
| En-tetes de date         | oui            | non                                                             |
| Pagination               | non            | oui                                                             |
| Filtres par onglet       | non            | oui                                                             |

Deux manques identifies, NON traites dans cette release, candidats a un ticket :

- Impossible de supprimer une notification depuis la page plein ecran, alors
  que le panneau le permet. Ce n'est pas une difference de mise en page mais
  une capacite absente d'un cote.
- Pas de separateurs de date sur la page, alors que c'est justement la, sur une
  liste longue et paginee, qu'ils seraient le plus utiles.

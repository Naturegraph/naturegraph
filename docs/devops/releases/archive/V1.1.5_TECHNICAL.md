## Bugs fixes

### 1. Bouton Contribuer profil mobile

**Symptome** : Sur le profil mobile, clic + ouvrait directement le panel
Rencontre Nature sans permettre de choisir Instant Nature. Incoherent
avec le feed Home ou le user a le choix.

**Cause** : Profile.tsx wirait `MobileNavLayer` avec
`onContributeClick={() => openCreate('nature_encounter')}` qui forcait
le type Rencontre.

**Fix** : Remplace par `setShowContributeModal(true)` + render de
`<ContributeModal />` avec `onTypeSelect={handleContributeTypeSelect}`.
Meme pattern que la home pour coherence flow.

### 2. Sauvegarde profil pour champs vides

**Symptome** : Si l user clear sa bio / reseau social / site web, le
save n a aucun effet. Aucune erreur visible.

**Cause** : Dans `Profile.handleSave`, la map etait
`instagram: data.instagram ?? undefined`. Quand `data.instagram` est
null (champ vide), `null ?? undefined` retourne `undefined`. Le
`updateProfile` du service Supabase ignore les champs undefined dans
l UPDATE -> 0 changement en DB.

**Fix** :

- `UpdateProfilePayload` : passe de `bio?: string` a `bio?: string | null`
  pour bio, city, region, country, instagram, twitter, facebook, website
  (les colonnes nullable en DB).
- `first_name` et `last_name` restent `string` (NOT NULL en DB).
- `Profile.handleSave` : `data.instagram === undefined ? undefined : data.instagram`
  pour propager null explicitement. Supabase UPDATE SET instagram = NULL.

### 3. Bouton X pour clear rapide (UX bonus)

Ajoute un composant `ClearButton` dans `EditInfoTab` :

- Petit cercle X discret a droite de chaque input Instagram / Facebook / Site
- Visible uniquement si le champ a une valeur
- Click -> setter('') -> save envoie null -> DB efface

Permet de vider rapidement sans avoir a tout supprimer a la main.

EditPhotoTab inchange : envoyait deja `{ avatar_url: null }` pour le
bouton Supprimer.

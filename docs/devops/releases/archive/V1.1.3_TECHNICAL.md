## NG tickets fixes

### NG-001 - Reactions desynchro feed <-> profil (Haute)

**Cause racine** : la table `reactions` n avait que les policies RLS
INSERT / DELETE / SELECT. Aucun policy UPDATE -> tout UPDATE etait
silencieusement bloque. Le code `postService.toggleReaction` faisait un
UPDATE atomique sur swap d emoji (love -> wow) pour ne pas declencher
2x les triggers de notification, mais 0 rows etaient affectees. Au refetch,
`getUserReactions` retournait l ancienne valeur -> UI flip back.

**Fix** :

- Migration `add_update_policy_reactions_ng001_fix.sql` : ajout policy
  `Users can update own reactions`.
- `useUserPosts` enrichit maintenant `user_reaction` + `reactions_breakdown`
  apres fetch (comme `useFeed`).
- `useToggleReaction.onMutate` polymorphe : gere les 3 shapes de cache
  (feed `{data,pagination}`, profil array nu, post detail single).
- Cache key exact reconstitue dans `ProfileFeed` pour que `setQueryData`
  matche bien le cache.

### NG-002 - Edition observation depuis le profil (Haute)

**Cause** : `PostOptionsMenu.onEdit` etait cable uniquement dans Home.tsx.
Le profil rendait FeedPost sans `onEditPost`, le bouton "Modifier" etait
absent.

**Fix** :

- Nouveau hook partage `useEditPostFlow` (Home, Profile, PostDetail).
- Panel ContributeEncounterForm / ContributeInstantPanel rendu inline
  dans le profil (pas de redirect vers /).
- Lazy load des panneaux centralise dans le hook.
- En mode edition, lazy init `step = 3` direct (skip photos).

### NG-004 - Instabilite produit (Critique, partiel)

**Symptomes adresses** :

1. App necessite refresh manuel -> `queryClient.clear()` au SIGNED_OUT
   - `invalidateQueries()` au SIGNED_IN. Sync auth multi-onglets via
     `storage` event. Plus de fantomes de l ancien user.
2. Routing landing apres auth -> deja resolu V1.0.4 (PublicRoute).
3. Ecran blanc sur erreur -> `AppErrorBoundary` global au-dessus de
   QueryClientProvider + RouterProvider, UI de recuperation propre.
4. Erreurs silencieuses au submit Partager -> auto-save brouillon
   localStorage TTL 30 min (`useContributeDraft`), restauration au mount
   via lazy init useState, purge au submit reussi.

**Symptomes restants** (a monitorer en prod) : session instable, perte
etat authentifie sur 30 min d usage. Code en place, validation prod
necessaire.

### NG-008 - Streak hebdomadaire (Moyenne)

**Fix** :

- i18n FR `Jours` -> `Semaines` / EN `Days` -> `Weeks`.

### NG-009 - Date observation distincte (Moyenne+)

- Affichage text-xs italic mute sous date/location, masque si identique
  (anti-bullet orphelin).
- i18n FR/EN : nouvelle cle `home.post.observedOn`.

### NG-010 - Galerie masonry (Moyenne)

**Fix** :

- `_gallery.scss` : `font-size: 0` + `line-height: 0` sur
  `.gallery-masonry` pour eliminer le whitespace de `inline-block`.

- Reset `initial` sur les enfants (img, badge, overlay).
- `margin-bottom == column-gap` pixel-perfect : 2px mobile, 3px tablet+.

### NG-011 - Reseaux sociaux profil (Moyenne)

**Scope V1.1.3 final** (decision Nicolas, volontairement minimal pour beta) :

- Facebook (nouvelle colonne DB)

**Fix** :

  Style coherent (icon + texte primary souligne, fallback prefix

- i18n FR/EN : titre `Reseaux sociaux et lien externe` + placeholders

## Refactor qualite

### Hook partage `useEditPostFlow`

Avant : Home, Profile, PostDetail dupliquaient l etat panel + lazy imports.

Apres : un seul hook `useEditPostFlow()` qui retourne :

- `onEditPost(postId, type)` : pour les FeedPost / PostOptionsMenu
- `openCreate(type)` : pour les boutons "Contribuer"
- `panelNode` : JSX du panneau a rendre dans le composant racine
- `isPanelOpen` : pour conditionner d autres comportements

Lazy load centralise (un seul chunk pour les 3 pages).

### Mutations cache global au sign in/out

- `signOut` -> `queryClient.clear()` : nettoie completement le cache
  pour eviter les fantomes du user precedent.
- `signIn` -> `queryClient.invalidateQueries()` : repart sur des donnees
  fraiches au cas ou.

### Sync multi-onglets auth

```ts
window.addEventListener('storage', (e) => {
  if (e.key === 'naturegraph-auth' || e.key === null) {
    supabase?.auth.getSession().catch(() => {})
  }
})
```

Detecte les changements `localStorage` cross-tabs -> propage le
SIGNED_OUT / SIGNED_IN aux autres onglets.

### AppErrorBoundary global

Wrappee autour de `QueryClientProvider + RouterProvider` dans `main.tsx`.
Capture les erreurs de rendu React, log avec `componentStack`, affiche
UI de recuperation avec boutons "Recharger l app" / "Retour au feed".

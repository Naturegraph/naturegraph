- **Honeypot** anti-bot (champ cache, hors flux + `aria-hidden` + `tabIndex -1`) :
  rempli => succes feint sans INSERT. Aucun captcha ni appel reseau.

  "recevoir les nouvelles" n'a de sens qu'en phase marketing (MailerLite, aout).
  Reversible en 1 ligne. La mention transactionnelle + le lien politique de
  confidentialite restent affiches (transparence RGPD, hors marketing).

## 1. Note technique

### 1.1 Bouton Publier "mort" au retour d'arrière-plan (le gros)

**Cause** : quand l'OS gèle l'app pendant une publication, la requête en vol meurt
sans jamais rejeter et le watchdog (`setTimeout`) est gelé -> le verrou `inFlightRef`
reste bloqué -> le bouton Publier est mort, et **rien dans Sentry** (une page gelée
n'émet rien ; Sentry ne le voyait qu'en rage-click sur bouton `disabled`).

**Correctif** (dans `useContributePostSubmit`) :

- Écouteur de reprise DANS le hook : au retour au premier plan pendant un submit "en
  vol" (après > 4 s d'absence), on **relâche le verrou** (`inFlightRef` /
  `isSubmitting`). Le bouton **revit**, la saisie est **gardée** (brouillon +
  photos IndexedDB), l'utilisateur re-tape et ça part. **Fini le "il faut fermer
  l'app"**.
- **Garde-fou anti-zombie (epoch)** : un pipeline gelé qui repartirait après coup ne
  peut ni **doubler** le post ni **écraser** l'état d'une nouvelle tentative.
- **Nettoyage de l'orphelin** créé avant le gel (limite les fausses notifs "X a
  publié" sur un post vide). Le lien est coupé dès que le post est **complet** ->
  **zéro risque** de supprimer un post réussi.
- **Traçé dans Sentry** : `trackFailure publish.interrompu-arriere-plan` -> le cas
  devient enfin visible.

### 1.2 Sentry plus sobre (quota)

- **Session Replay DÉSACTIVÉ** : il saturait le forfait gratuit. Le diagnostic reste
  assuré par erreurs + breadcrumbs + `trackFailure` (échecs silencieux) + rage-click.
- **Bruit navigateurs in-app** Instagram/Facebook filtré (`Java object is gone`,
  `navigation_performance_logger`) : ce ne sont pas nos bugs.

### 1.3 Upload : NotFoundError

`NotFoundError` (référence photo disparue) traité comme `NotReadableError` (même
famille "fichier illisible/disparu", vu mobile ET desktop Safari) -> message
actionnable + warning au lieu d'une issue d'erreur.

## 2. Note user-friendly (changelog)

**Fini le bouton Publier bloqué.**

Si tu quittais l'app une seconde pendant l'envoi d'une publication, le bouton pouvait
rester "mort" et il fallait tout fermer. C'est corrigé : au retour, l'app se
débloque toute seule, ta saisie et tes photos sont gardées, tu réappuies sur Publier
et c'est envoyé. On a aussi allégé notre outil de surveillance.

C'est la première étape d'un gros chantier de fiabilité (reconnexion automatique
après veille, etc.) qui arrive juste après.

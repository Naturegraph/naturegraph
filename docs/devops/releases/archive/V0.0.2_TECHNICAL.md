# Release V0.0.2 — Stabilisation prélancement (technique)

> Date : 2026-06-23 · Tag : `v0.0.2` · Branche : `main` (prod)
> Précédent : `v0.0.1` (base officielle prélancement)
> Force-logout : NON · Migration : 1 (déjà appliquée en prod) · Notif in-app : non

Grappe de stabilisation et durcissement avant l'envoi du mail ciblé de
prélancement (80-100 personnes). Aucune rupture de compatibilité.

## Sécurité (NG-007)

- Revue ligne par ligne des 7 Edge Functions : autorisations correctes, pas
  d'IDOR. Finding documenté : `send-waitlist-confirmation` non authentifiée
  (à sécuriser avec le chantier email NG-009).
- Re-scan `get_advisors` PROD : findings inchangés, tous by-design (RPC
  SECURITY DEFINER + RLS).
- **6 vulnérabilités Dependabot corrigées** via overrides (undici 6.27/7.28,
  js-yaml 4.2, esbuild 0.28.1) — toutes des deps dev/build, hors bundle client.
- Fichiers meta GitHub, LICENSE proprietaire, liens partenaires corrigés.

## DNS & domaines (NG-008)

- `naturegraph.fr` redirige désormais en **HTTPS 308** vers `naturegraph.ca`
  (bascule de Hostinger vers Vercel pour le SSL automatique). Runbook DNS créé.

## Email (NG-009)

- Migration de toutes les adresses de la plateforme de `naturegraph.fr@gmail.com`
  vers `@naturegraph.ca` (UI, i18n, templates Supabase, edge function, sécurité).
  Source de vérité centralisée dans `src/constants/contact.ts`.

## Stabilité — publication / upload (NG-012)

- **Anti-doublon de post sur réseau lent** : verrou in-flight + watchdog « sans
  progression » (ne se déclenche plus que sur un vrai blocage).
- Timeout createPost 10→20s (l'INSERT peut dépasser 10s sur 3G/4G rurale).
- Pas de navigation tardive (onSuccess) après un abandon watchdog.

## Auth / session (NG-003)

- Fix race condition au boot PWA : plus de redirection à tort vers `/onboarding`
  à l'ouverture (TOKEN_REFRESHED avant chargement du profil → onboarding=false).

## Performance feed (NG-026)

- Lazy-load des couvertures du feed sauf le 1er post (above-the-fold/LCP) :
  les covers ne se téléchargent plus toutes d'un coup sur un feed long.

## Notifications

- **Anti-spam** : regroupement des notifs « nouveau post » **par auteur**
  (« X a publié N publications ») au lieu de N lignes.
- **Préférences par type** dans les Paramètres (Réactions / Migrateurs /
  Publications), branchées sur `notification_preferences` (les triggers
  respectent déjà `is_notif_enabled`).
- **Fix bouton Supprimer** : ajout de la policy RLS DELETE manquante (migration
  `20260623_notifications_delete_policy.sql`, déjà appliquée en prod).
- **Badge PWA** : compteur de non-lues sur l'icône de l'app installée
  (`AppBadgeSync` au niveau app), feature-detecté.

## Pages d'erreur (NG-021)

- Pages **404 / 403 / 500** refondues (carte + écusson hermine, fond DS),
  noindex, Sentry branché sur l'ErrorBoundary, aucun détail technique exposé.

## Outillage (NG-025 / NG-026)

- Norme de versioning SemVer + Conventional Commits (déjà en place depuis v0.0.1).
- Suppression des tirets cadratin / marqueurs IA dans le repo.

## Vérifications

- `npm run build` OK · `npm run lint` 0 erreur · **78 tests verts** · `npm audit`
  0 vulnérabilité.

## NG tickets resolus

### NG-004 - Instabilite PWA / session / navigation (deja livre Phase 1)

- Toast persistant connexion + invalidate stats au login
- OnlineStatusBanner (banniere connexion / hors-ligne)
- AuthContext visibility refresh apres 10 min absence onglet
- React Query : refetchOnWindowFocus + retry 5xx backoff exponentiel
- gcTime explicite 10 min queries / 5 min mutations (memory leak prevention)
- AuthContext sync multi-tabs via storage event
- queryClient.clear() au SIGNED_OUT
- AppErrorBoundary global au-dessus du router

### NG-004B - Redirection auto + restauration session apres auth

- `PublicRoute.tsx` : optimistic redirect si token localStorage present
  (`hasLocalSessionHint()`). Si session morte, ProtectedRoute renvoie /login.
- `Welcome.tsx` : spinner pendant isLoading session au lieu de la vue
  initiale avec boutons "J'ai un code" / "Waitlist".
- `AuthPage.tsx` : useEffect fallback navigate si isAuthenticated devient
  true en mode verification login (au cas ou le navigate primaire echoue).

### NG-012 - Open Graph apercus partage social

- `api/post-og.ts` (Vercel Function) : route /post/:id via rewrite vercel.json
- `api/profile-og.ts` : route /profile/:username via rewrite
- Detection User-Agent crawler (WhatsApp, Discord, Facebook, X, LinkedIn,
  Telegram, Apple iMessage, Slack, etc.)
- Fallback og-preview.png si pas d image
- Image servie via Supabase render endpoint pour resize < 200 KB
- **Fix racine 2026-06-01** : GRANT EXECUTE sur is_internal_user +
  can_see_post pour anon, car la vue posts_public utilise ces fonctions
  dans son RLS. Sans grant, le query PostgREST anon renvoyait 42501 et
  la fonction Vercel servait toujours le fallback.

### NG-013 - Loader officiel Naturegraph

- `src/components/ui/AppLoader.tsx` : video webm (36 KB asset fourni
  Nicolas) + fallback Spinner CSS si webm non supporte
- Respect prefers-reduced-motion
- 3 tailles : sm / md / lg, mode inline disponible
- Integrations : router LazyPage Suspense, PublicRoute, ProtectedRoute,
  Welcome.tsx
- **BootSplash systematique** (QA round 8) : App.tsx wrapper qui force
  l affichage AppLoader 900ms au premier mount, pour branding
  systematique meme si session check est instantanee.

### NG-014 - Icone PWA rognee a l installation

- `public/manifest.json` : split en 2 entries `purpose: "any"` (192 + 512)
  au lieu de `purpose: "any maskable"` qui forcait Android a cropper.
- `index.html` : favicon.png 257px pour onglet navigateur (asset Nicolas),
  hermine 180px pour apple-touch-icon.
- Assets ranges : `Favicon.png` -> `public/favicon.png`,
  `App Loading.webm` -> `src/assets/branding/app-loading.webm`.

### NG-021 - Perte donnees changement onglet profil

- `EditProfilePanel.tsx` : passage de conditional render `{activeTab === 'info' && ...}`
  a CSS `hidden={activeTab !== 'info'}`.
- Les 3 tabs (Info / Prefs / Photo) restent montees tant que le panel est

### NG-022 - Recherche pas appliquee visuellement

- `getFeed` : `.eq('taxref_id', filters.taxrefId)` si defini

### NG-023 - Especes + categories cliquables dans posts

- Especes : `FeedPost.tsx` `isSpeciesClickable = !!taxref_id` (etait
  hardcoded false depuis 2026-05-22). Click chip espece -> `setActiveSpecies`

- Categories : nouveau callback `onSelectCategory?: (group: string) => void`

### NG-024 - Bug critique : edition images publication

  existingMedia vide -> aucune photo affichee.

- UI unifiee creation + edition : EncounterStep1 fusionne `existingMedia`

## Refactor qualite

### Slots unifies EncounterStep1

```ts
type Slot =
  | { kind: 'existing'; id: string; url: string; storagePath: string }
  | { kind: 'file'; fileIndex: number; url: string }
const slots: Slot[] = [
  ...(existingMedia ?? []).map(...),
  ...files.map(...),
]
```

Le BigPreview affiche `slots[safeIndex].url`. La ThumbRow rend tous les
slots. Le `removeSlot(slot)` dispatche selon kind (delete API pour
existing, retrait local pour file).

### Event custom naturegraph:open-search

Permet a un composant enfant (FeedSection mobile pill) de declencher
l ouverture d un panel dans un autre composant (MobileNavLayer) sans
prop drilling ni context refactor. Pattern reutilisable.

### Exclusivite panels via state unique

```ts
const [activePanel, setActivePanel] = useState<ActivePanel>(null)
const showSearch = activePanel === 'search'
// ...
const togglePanel = (panel) => setActivePanel((prev) => (prev === panel ? null : panel))
```

Plus robuste que 5 useState independants + wrappers (qui souffraient
de bugs de batch React et closure stale).

GRANT EXECUTE ON FUNCTION public.is_internal_user TO anon, authenticated;

posts_public. La vue applique RLS qui appelle ces 2 fonctions. Sans

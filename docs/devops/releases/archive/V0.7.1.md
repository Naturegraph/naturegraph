## 1. Note technique

### 1.1 NG-053 : swipe tactile dans le viewer plein ecran (mobile)

- Ajout du **swipe horizontal** gauche/droite pour naviguer entre les photos en
  plein ecran (`PhotoLightbox`). Seuil 50px, geste ignore s'il est majoritairement
  vertical.
- Fleches, clavier et miniatures conserves (desktop + accessibilite) : aucune
  regression. Le contexte (espece + lieu) et l'indicateur X/Y etaient deja en place.

### 1.2 NG-064 : UX zero-resultat de la recherche d'espece

- Etat "aucune espece trouvee" enrichi d'un lien **« Signaler une espece
  manquante »** : ouvre le mail vers le support avec le terme cherche pre-rempli
  (sujet + corps). La publication n'est **jamais** bloquee (« Je ne connais pas
  l'espece » reste dispo).
- **Monitoring** : chaque terme sans resultat est loggue une fois dans Sentry
  (dedoublonne) pour alimenter la liste d'enrichissement de la base (lie NG-057).
- Helper `mailtoLink()` etendu (retro-compatible) pour accepter un corps de message.
- Le coeur de la recherche (ranking, accents, perf) etait deja livre en V0.4.5.

### 1.3 NG-051 : completion des traductions anglaises

- **228 cles** etaient utilisees en code via `t('cle', { defaultValue: 'francais' })`
  sans exister dans les fichiers de langue : en francais tout paraissait normal
  (repli sur le defaultValue), mais **en anglais l'app affichait du francais**.
- Ajout des **228 cles dans `fr.json` ET `en.json`** (traductions EN redigees),
  parite totale verifiee par script : **1384 = 1384**, zero ecart.
- **8 chaines** utilisaient une interpolation JS `${}` dans le defaultValue :
  converties en `{{var}}` i18next (la variable etait deja passee en option pour
  7/8 ; ajout de `failed`/`total` pour `partialUploadError`).
- Retrait de **2 cles-chaines mortes** (`settings.notifications`, `settings.logout`)
  qui bloquaient l'imbrication des cles reellement utilisees (non referencees, cf grep).

## 2. Note user-friendly (changelog / communication)

**Un viewer photo plus fluide, une recherche plus utile, et l'anglais au complet.**

En plein ecran sur mobile, tu peux maintenant **glisser** pour passer d'une photo
a l'autre. Quand une espece n'est pas trouvee a la publication, un lien te permet
de **la signaler** en un clic (et tu peux toujours publier sans). Et pour nos
utilisateurs anglophones, toute l'interface est desormais **entierement traduite**.

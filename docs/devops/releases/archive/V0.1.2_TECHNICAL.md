> Date : 2026-07-09 · Tag : `v0.1.2` · Branche : `main` (prod)

PATCH UI : dans Parametres > Notifications, la section "Methodes de
notification" passe d'un radio exclusif (in-app / email / aucune) a deux
toggles INDEPENDANTS, cochables ensemble. Demande Nicolas : pouvoir recevoir
a la fois dans l'application ET par courriel.

## Contenu

- **SettingsNotificationsView** : "Dans l'application" et "Par courriel" sont
  desormais deux toggles independants.
  - "Par courriel" -> user_settings.email_notifications (master email global).
  - "Dans l'application" -> cloche = au moins un type actif ; la bascule
    active/coupe les 3 types (reaction/follow/post) en PRESERVANT le canal
    email de chaque type (les 2 canaux sont independants).
  - "Aucune notification" devient un raccourci : coche quand tout est coupe,
    coupe cloche + email au clic.
- Suppression du type `DeliveryMethod` et de la logique de radio exclusif.

- Round-trip DB inchange cote backend (is_notif_enabled / is_email_enabled).

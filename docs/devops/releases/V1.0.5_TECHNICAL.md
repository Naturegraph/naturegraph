### Nouvelle BDD taxonomique : `taxonomy_nodes`

Migration `20260526_taxonomy_nodes_hierarchical_schema.sql` :

- Table unifiee avec `rank` enum (`class`, `order`, `family`, `genus`,
  `species`, etc.)
- `parent_id` self-FK pour la hierarchie
- Denormalisation `kingdom`, `phylum`, `class`, `"order"`, `family`, `genus`
  pour eviter CTE recursives dans les queries du feed
- 9 indexes optimises (B-tree + partial + GIN trigram)
- RLS public read + admin write
- FK ajoutee a `posts.taxonomy_node_id` (additif, ne casse rien)

Migration `20260526_taxonomy_future_proof_metadata.sql` :

- `metadata` JSONB extensible (pour statuts conservation IUCN/COSEWIC/SARA,
  protection, habitats, biologie... a venir sans migration cassante)
- `data_version` + `data_source` pour audit/traceabilite

### Seed BDD : 43 823 nodes iNaturalist FR + CA

Script `scripts/seed-taxonomy-v2.ps1` (PowerShell, idempotent) :

- Source : iNaturalist API (place_id 6753 FR, 6712 CA)
- 8 classes : Aves, Mammalia, Amphibia, Reptilia, Insecta, Arachnida, Mollusca, Actinopterygii
- 1 500 familles d insectes (FR + CA)
- 42 315 especes :
  - Aves : 1 617 (1133 FR + 1029 CA dont 545 migratrices partagees)
  - Mammalia : 696
  - Amphibia : 179
  - Reptilia : 530
  - Insecta : 33 098
  - Arachnida : ~2 800
  - Mollusca : ~2 300
  - Actinopterygii (poissons) : ~1 800

Idempotence via `UNIQUE(rank, scientific_name)` + `Prefer: resolution=merge-duplicates`

- `?on_conflict=rank,scientific_name` dans l URL PostgREST.

### RPC `search_taxonomy()` v2

Migrations `20260526_taxonomy_search_rpc.sql` + `20260526_taxonomy_search_rpc_v2.sql` :

```sql
search_taxonomy(
  p_query TEXT,
  p_territory TEXT DEFAULT NULL,        -- 'fr', 'ca' ou NULL
  p_ranks TEXT[] DEFAULT ARRAY['species','family','order'],
  p_class_filter TEXT DEFAULT NULL,
  p_max_results INTEGER DEFAULT 20
) RETURNS TABLE (id, rank, scientific_name, common_name_fr, common_name_en,
                 class, "order", family,
                 available_in_fr, available_in_ca, inaturalist_id,
                 photo_url, popularity, match_score)
```

Permet au front (a venir V1.1.0) d afficher :

- Especes precises + familles dans une seule recherche
- Drapeaux territoire (FR / CA)
- Lien vers fiche iNat
- Ranking : species > genus > family > order, puis match_score, puis popularity

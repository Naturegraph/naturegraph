### Versioning officiel V1.0.0+

- Strategie semver V[MAJOR].[MINOR].[PATCH] type SaaS / jeu video
- PATCH : bugfix, cleanup, optim
- MINOR : nouvelles features, UX majeure
- MAJOR : refonte architecture, business

### Process release officialise

- Plus de push prod systematique
- Release note obligatoire (technique + user-friendly), validation Nicolas
- Force-logout users seulement pour MAJ critiques auth/schema

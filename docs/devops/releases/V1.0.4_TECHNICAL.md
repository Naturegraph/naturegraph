## Changements

### Fix bug critique OTP (signale par Nicolas en prod V1.0.3)

- **Symptome** : user saisit son code OTP 6 chiffres, rien ne se passe visuellement,
  il reste sur l ecran de verification. Necessite F5 manuel pour que le login prenne
  effet. Beaucoup de users beta bloques sans penser a refresh.
- **Cause** : `verifyOtp()` dans AuthContext retournait juste `{error}` et comptait
  sur le listener `onAuthStateChange` pour propager la session au state React. Cette
  propagation est asynchrone, donc `handleVerificationSuccess` (qui suit `onSuccess`)
  declenchait `goto.home()` AVANT que `isAuthenticated` soit a `true`. Le guard sur
  `/home` renvoyait alors silencieusement vers `/login`.
- **Fix** : `verifyOtp()` lit `data.session` / `data.user` de la response Supabase
  et fait `setState()` synchrone via `deriveState()`. Garantie : `isAuthenticated`
  est `true` au moment ou `onSuccess` est invoque, le `goto.home()` reussit du premier
  coup.
- **Impact** : tous les flows OTP (login + signup post-OTP) corriges. Mode demo
  inchange (deja synchrone).

### Security overrides npm (package.json)

Ajout du champ `overrides` pour forcer les sous-dependances vulnerables a
des versions corrigees, sans toucher au reste de l arbre :

```json
{
  "overrides": {
    "@vercel/node": {
      "undici": "^6.24.0",
      "path-to-regexp": "^6.3.0",
      "ajv": "^8.18.0"
    },
    "@vercel/python-analysis": {
      "minimatch": "^10.2.3",
      "smol-toml": "^1.6.1"
    }
  }
}
```

### Vulnerabilites resolues (8 au total)

| Package        | Severite | CVE / Issue                                                    |
| -------------- | -------- | -------------------------------------------------------------- |
| undici         | medium   | CRLF Injection via `upgrade` option                            |
| undici         | medium   | HTTP Request/Response Smuggling                                |
| undici         | low      | Denial of Service via bad certificate data                     |
| undici         | medium   | Use of Insufficiently Random Values                            |
| minimatch      | HIGH     | ReDoS combinatorial backtracking via multiple GLOBSTAR         |
| path-to-regexp | high     | Outputs backtracking regular expressions                       |
| ajv            | moderate | ReDoS when using `$data` option                                |
| smol-toml      | moderate | DoS via TOML documents containing thousands of commented lines |

### Contexte des packages

`@vercel/node@5.8.4` est la derniere version disponible mais ses
dependances transitives sont obsoletes. Les overrides ciblent uniquement
les sous-arbres `@vercel/node` et `@vercel/python-analysis` pour ne pas
affecter les autres consommateurs (ex : jsdom utilise undici@7.x qui
n est pas vulnerable).
